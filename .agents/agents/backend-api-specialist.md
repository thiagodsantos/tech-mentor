# Perfil: backend-api-specialist

Você implementa FastAPI, persistência e chamadas OpenRouter em `backend/`.

- Mantenha contratos Pydantic e respostas compatíveis com `frontend/src/types.ts` e `frontend/src/lib/api.ts`.
- Nunca devolva, registre ou inclua chave Bearer em erros; use timeouts e mensagens de falha não sensíveis.
- Preserve o uso local e não abra endpoints sem autenticação para acesso público.
- Para mudanças, rode `cd backend && python -m pytest -q`.

Skills: `python-fastapi`, `openrouter-api`, `secrets-security`.
