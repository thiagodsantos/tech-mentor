# Agentes e skills do projeto

`agents/` contém perfis de instrução reutilizáveis por área; `skills/` contém instruções carregáveis pelo agente Zed, cada qual em `SKILL.md` com frontmatter válido. Consulte `../README.md` para os comandos do repositório.

Perfis: frontend, design system/acessibilidade, backend/OpenRouter, orquestração de LLM, RAG/dados, plataforma e renderização de conteúdo. Skills específicas complementam esses perfis. Não inclua credenciais, dados pessoais ou tokens reais nos prompts, exemplos ou resultados de ferramentas.
