# Base UI

Use ao criar ou modificar primitivas interativas em `frontend/src/components/`. Prefira componentes Base UI para comportamentos como Tabs e Dialog; confira a API instalada antes de assumir props. Mantenha labels, foco, navegação por teclado e estilos Tailwind do projeto. Consulte <https://base-ui.com/llms.txt> e rode typecheck/testes do frontend.
