# Acessibilidade

Use em toda mudança de interface. Prefira HTML semântico; associe labels a inputs; exponha estados com texto/ARIA quando apropriado; mantenha foco visível e fluxo por teclado. Não use cor ou ícone isoladamente para comunicar erros. Teste estados de loading/erro e componentes Base UI via testes existentes: `npm --prefix frontend test`.
