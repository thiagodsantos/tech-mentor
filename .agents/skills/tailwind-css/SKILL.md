# Tailwind CSS

Use ao alterar `frontend/src/styles.css`, classes ou `frontend/tailwind.config.js`. Reutilize cores, espaçamentos e variantes existentes; evite estilos inline e regras globais desnecessárias. Mantenha responsividade e estados hover/focus/disabled. Valide o build Vite, que executa a compilação Tailwind.
