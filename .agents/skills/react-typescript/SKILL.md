# React e TypeScript

Use ao alterar componentes React em `frontend/src/`. Prefira props e estados tipados, componentes pequenos e hooks existentes; evite `any` e efeitos que duplicam dados derivados. Preserve os contratos em `frontend/src/types.ts` e os padrões de componentes do projeto. Valide com `npm --prefix frontend run typecheck` e `npm --prefix frontend test`.
