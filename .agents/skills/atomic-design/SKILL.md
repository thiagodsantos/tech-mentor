# Atomic Design

Use ao estruturar UI em `frontend/src/components/`. Reutilize a organização `atoms/`, `molecules/` e `organisms/`; páginas compõem esses blocos. Extraia componentes quando houver comportamento/presentação reutilizável, não apenas para fragmentar JSX. Preserve acessibilidade e dependências unidirecionais. Verifique as telas existentes antes de criar componentes duplicados.
