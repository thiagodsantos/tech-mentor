# Avaliação de LLM

Use ao modificar prompts ou estrutura de aula. Crie casos de teste pequenos e verificáveis para seções obrigatórias, coerência do Markdown, exemplos e diagramas; simule provider no CI e não use snapshots frágeis de texto completo. Não declare referências verificadas sem checagem real. Execute `cd backend && python -m pytest -q`.
