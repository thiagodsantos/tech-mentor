# Docker Compose

Use ao editar `docker-compose.yml` ou Dockerfiles. Mantenha portas bindadas em loopback, segredos via `.env` ignorado, health checks e dependência de prontidão. Preserve volumes por padrão e destaque comandos destrutivos. Valide com `docker compose config` e teste startup se Docker estiver disponível.
