# Python e FastAPI

Use para alterações em `backend/app/`. Mantenha handlers pequenos, use schemas Pydantic, dependências async existentes e erros HTTP claros sem detalhes internos. Isole chamadas externas em serviços e cubra rotas com mocks. Valide com `cd backend && python -m pytest -q` e `python -m compileall -q backend/app`.
